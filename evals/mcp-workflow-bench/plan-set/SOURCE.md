# Plan-set sources

Every real sheet here is a public government record: a U.S. Department of Veterans
Affairs construction solicitation attachment posted on SAM.gov (`accessLevel: public`),
or a municipal plan the city itself publishes as public domain. Document metadata has
been stripped; drawings are otherwise as posted. Redistributed for engineering test
purposes only; the A/E named on each sheet retains whatever rights it holds. If you are
a rights holder and want a sheet removed, open an issue. The bar for adding a plan is
the same: a public government posting, cited by notice id or program page. Never add a
client or private planset.

Extraction: single pages were copied with PyMuPDF (`insert_pdf`), metadata and XMP
removed, saved with `garbage=4, clean=True`. The page rotation attribute is preserved so
the displayed orientation, and therefore the tool coordinate frame, matches the original
set; the extracted pages' axis-aligned linework was checked segment-for-segment against
the original pages in the same frame before commit.
