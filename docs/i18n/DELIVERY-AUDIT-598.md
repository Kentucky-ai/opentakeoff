# Повторная проверка русской локализации PR №598

Проверка от 4 ноября 2026 года выполнена на ветке `russian-localization`, поверх `6b09edc`. Использовались только искусственные данные и общедоступный пример чертежа.

## Исправления

- Служебные заголовки экспорта переводятся отдельно от данных. Названия `Report`, `Work`, код `001.20`, пользовательские графы, названия листов и примечания не пропускаются через общий переводчик.
- В CSV десятичная запятая применяется к числовым значениям до сериализации. Код `001.20` сохраняет точку. Сохранены экранирование кавычек, многострочного текста и защита от формул. Русский CSV содержит BOM и разделитель `;`.
- В XLSX коды остаются строками, количества и суммы — числами. Длинные русские названия и заголовки переносятся; высота строк учитывает переносы.
- В редактируемых полях материалов и библиотеки показывается сохранённое значение. Названия проектов, редакций, листов и пользовательских граф не переводятся как команды интерфейса. Для известных марок покрытий используется отдельная функция описания.
- Сообщения открытия архива, импорта измерений, принятия предложений агента и массового удаления используют точные ключи с параметрами. Вложенное сообщение переводится явно. Исправлены подписи цен для экранного диктора, поле основания и подсказка условий коммерческого предложения.
- Ведомость переносит длинные названия. На узком окне английская панель команд переносится, сохраняя кнопку закрытия справа вверху.
- PDF с измерениями переносит названия внутри столбцов и продолжает длинные строки на следующей странице. В коммерческом предложении длинное наименование занимает отдельную широкую строку над своими количеством и стоимостью.

## Контрольный проект и сверка

Четыре вида работ: `Report`, `Work`, `001.20` и длинное русское наименование. У каждого измерено 100 кв. футов, запас 5%, материал — 2 за кв. фут, работа — 3 за кв. фут, вспомогательный материал `Work` — одна упаковка стоимостью 20. Название проекта — `Report`, заказчик — `Work`.

| Показатель | Ожидается | Получено |
| --- | --- | --- |
| Объём одного вида работ | 100 кв. футов = 9,290304 м² | 9,29 в смете; 9,3 в ведомости с её точностью |
| Материал с запасом | 105 кв. футов = 9,7548192 м² | 9,75 в CSV и смете |
| Материалы одной позиции | 105 × 2 + 20 | 230 |
| Работы одной позиции | 100 × 3 | 300 |
| Стоимость одной позиции | 530 | 530 в интерфейсе, XLSX и PDF предложения |
| Общая стоимость | 2120 | 2120 до и после Русский → English → Русский |
| Общая площадь с запасом | 420 кв. футов = 39,0192768 м² | 39,02 в CSV; 39 в ведомости с её точностью |

В браузере выполнены импорт JSON через выбор единиц, переключение языка, экспорт CSV, Excel ведомости и сметы, PDF с измерениями и PDF предложения с ценами по позициям. Выгруженные файлы проверены отдельно: CSV по содержимому, XLSX по типам ячеек и значениям, PDF по извлечённому тексту и отрисованным страницам. Это не проверка открытия книги во всех версиях настольного Excel.

Открытие `.otk` поверх существующего проекта показало: «Открыт Report.otk — PDF: 1, измерений: 4. Предыдущие измерения сохранены в редакции. Восстановить их можно на панели „Редакции“». Английского хвоста нет.

При групповом удалении `Work` и `001.20` количество видов работ и измерений уменьшилось с четырёх до двух. Окно подтверждения временно заблокировало управление браузером; кратковременное итоговое сообщение не удалось зафиксировать. Его формулировка проверена автоматическим тестом. После проверки проект восстановлен из архива: снова четыре позиции и итог 2120. Принятие/пропуск предложений и варианты счётчиков 0, 1, 2, 5, 21 проверены форматированием сообщений; полный интерактивный сценарий принятия/пропуска агента не заявляется пройденным.

## Что остаётся за рамками этой проверки

Полная интеграция [84 составных мест](ru-sentences-598.md) остаётся задачей разработчика. Выбранные исправленные сообщения не означают, что весь интерфейс переведён без английских фрагментов: например, подсказки группы ожидающих предложений ещё используют старую сборку фраз. Rebase, перенос переключателя языка и модель валюты остаются у владельца проекта. Сейчас язык влияет на обозначение валюты в этой ветке; проверки подтверждают сохранность числовой суммы, а не конвертацию валют.

CSV не хранит типы ячеек. Его буквальный код сохранён, но табличная программа может самостоятельно распознать его как число при открытии. Для сохранения типа используйте XLSX либо импорт CSV с текстовым типом графы. Также эта проверка не заменяет испытания произвольных больших проектов, всех браузеров и отсутствующих моделей OCR/голоса.
