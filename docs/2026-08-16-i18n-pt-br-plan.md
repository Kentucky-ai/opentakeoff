# i18n Multi-language (pt-br First) — Implementation Plan

> **For agentic workers:** Use subagent-driven-development or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add i18n to OpenTakeoff with `react-i18next`, English default, pt-br first translation, auto-detect + manual selector.

**Architecture:** Namespaces per file group (`canvas`, `report`, `panels`, `guide`, `lib`), lazy-loaded via `i18next-http-backend` from `public/locales/{lng}/{ns}.json`. Non-component lib files use `i18n.t()` directly.

**Tech Stack:** `i18next`, `react-i18next`, `i18next-browser-languagedetector`, `i18next-http-backend`

## Task 1: Install Dependencies + Create i18n Config

**Files:**
- Create: `web/src/i18n/index.js`

- [ ] **Step 1: Install packages**

```bash
cd web && npm install i18next react-i18next i18next-browser-languagedetector i18next-http-backend
```

- [ ] **Step 2: Create `web/src/i18n/index.js`**

```js
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';
import HttpBackend from 'i18next-http-backend';
import LanguageDetector from 'i18next-browser-languagedetector';

i18n
  .use(HttpBackend)
  .use(LanguageDetector)
  .use(initReactI18next)
  .init({
    fallbackLng: 'en',
    supportedLngs: ['en', 'pt-br'],
    ns: ['canvas', 'report', 'panels', 'guide', 'lib'],
    defaultNS: 'canvas',
    interpolation: { escapeValue: false },
    backend: {
      loadPath: `${import.meta.env.BASE_URL}locales/{{lng}}/{{ns}}.json`,
    },
    detection: {
      order: ['localStorage', 'navigator'],
      lookupLocalStorage: 'i18nextLng',
      caches: ['localStorage'],
    },
  });

export default i18n;
```

- [ ] **Step 3: Import in `web/src/main.jsx`**

Add as first import (before React):

```js
import './i18n';
```

- [ ] **Step 4: Verify no crash**

```bash
cd web && npm run dev
```

Open http://localhost:5173 — app should load normally (no translations yet, fallback to `en` with missing keys).

- [ ] **Step 5: Commit**

```bash
git add web/package.json web/package-lock.json web/src/i18n/index.js web/src/main.jsx
git commit -m "feat(i18n): install i18next + config, lazy-load setup"
```

## Notes for Agents

- **String interpolation:** Always use `{{variable}}` syntax. Example: `t('status.created', { count: 5, tag: 'LVT-1' })`
- **Plurals:** Use ICU MessageFormat: `"{{count}} takeoff(s)"`. For complex cases: `"{{count}} {{"one" is "item", "other" is "items"}}"` (react-i18next handles this)
- **Namespaces:** Components use `useTranslation('namespace')`. Lib files use `i18n.t('key')` (auto-defaults to 'canvas' unless namespaced)
- **Fallback:** If a pt-br key is missing, i18next falls back to English automatically
- **Lazy loading:** Only the namespace requested by `useTranslation(ns)` loads — don't load all 5 at once
- **Test each change:** After extracting strings from a file, switch language and verify that file's UI changes
