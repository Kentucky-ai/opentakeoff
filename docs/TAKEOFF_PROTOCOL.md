# Takeoff Protocol — current work

OpenTakeoff is documenting its existing takeoff records as a versioned contract.
The [protocol draft](../protocol/README.md) defines Measurement, Calibration,
Provenance, Evidence, and Review, alongside a profile of today's browser/MCP
`opentakeoff.takeoff_canvas.v1` records.

The draft does not change the engine, saved-file format, MCP tools, One-Click
gate, or human approval rules. It is not a migration or Academy certification.

Start with the [field inventory](../protocol/INVENTORY.md),
[Academy compatibility report](../protocol/ACADEMY_COMPATIBILITY.md), and
[compatibility status](../protocol/COMPATIBILITY.md). Schema reference pages are
generated from the JSON schemas and checked in CI. The next steps are broader
compatibility fixtures, explicit adapters, then a shared human/agent wiki and
MCP knowledge resources. [Issue #405](https://github.com/Kentucky-ai/opentakeoff/issues/405)
tracks this first increment.
