# OpenTakeoff is moving to a new format. The new app goes live December 1, 2026.

We're replacing the current OpenTakeoff format with a new one that's more robust and more accurate. It's the base for the stronger takeoff tools and workflows we're building now.

**Takeoff stays free.** Measuring, counting and marking up plans will always be free. OpenTakeoff stays open source, and you can self-host it.

**Your projects come with you.** Existing takeoffs import into the new format, so you don't lose any work.

**The current version is being retired.** After December 1 it will no longer be updated. Move to the new app when it launches.

**One login for everything.** Create a free account at **[kentucky-ai.com](https://kentucky-ai.com)** before December 1. One sign-in covers the new app, the marketplace, AI connectors and MCP. Logins also show our volunteer developers and contributors who is using what they build, which keeps the community strong.

**AI and MCP users:** every takeoff action stays free when you run it through your own Claude or Codex.

**Marketplace:** optional add-ons live in the marketplace, behind the same login. The core takeoff tools never need them.

**Available December 1 for Mac, Windows and Linux** at [kentucky-ai.com](https://kentucky-ai.com).

Questions? [Open a Discussion](https://github.com/Kentucky-ai/opentakeoff/discussions).
