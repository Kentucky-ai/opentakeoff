# FEATURES.md — every capability, mapped to its code

The buildable map: what OpenTakeoff does and exactly where each piece lives, so you (or your coding agent) can extend a specific capability without spelunking. The UI for nearly everything is in `web/src/pages/TakeoffCanvas.jsx` (one deliberately monolithic component); the pure logic lives in `web/src/lib/`.

| Capability | What it does | Where the logic lives |
|---|---|---|
| **Ingest** | PDF, image, or `.zip` plan set — unpacked and normalized in-browser, multi-page, up to 4 sheets side-by-side | `web/src/lib/ingest.js`, sheet layout in `TakeoffCanvas.jsx` (`panels`, `panelAt`) |
| **Rendering** | pdf.js raster per sheet + **crisp detail-view**: past ~1.15× zoom the visible region re-renders from vectors at current zoom | render chain + detail-view effect in `TakeoffCanvas.jsx`; pdf.js (`pdfjs-dist`) |
| **Scale** | Auto-detect the drawn scale note per sheet; calibrate from a known dimension; per-sheet memory | `detectScale` in `web/src/lib/sheets.ts`; calibrate flow + `uppFor` in `TakeoffCanvas.jsx` |
| **Scale verification** | **Check a dimension (K)**: measure a printed dimension read-only, compare with what the drawing says (% error verdict, one-tap recalibrate); accepting any scale drops an ephemeral calibrated **ruler guide bar** on the sheet so a 2×-off scale is obvious before tracing | check flow + `showScaleGuide` in `TakeoffCanvas.jsx`; `ftIn`/`fmtCheckLen`/`parseLenInput` in `web/src/lib/units.ts` |
| **One-Click Area** | Click inside a room → flood-fill against PDF linework → traced polygon, vertices snapped to true corners. **Gap-tolerant:** a fill that leaks retries with walls sealed by 1–2 mask px (`dilateHard`), so hairline drafting gaps — wall runs that stop a pixel short — trace instead of failing; a real doorway never seals, and the rescue rides provenance (`origin.gap_bridged_px`). **Hatch-robust:** hatch/poché families are classified and made transparent to an escalated pass, so hatched rooms and tile grids fill to the real walls. **Scan-capable:** sheets with no vector linework build the boundary mask from rendered pixels instead (adaptive threshold + gap-bridging closing) and run the same flood/trace — results badged and stamped `raster_traced` | `web/src/lib/oneclick.ts` (`extractVectorGeometry` + per-segment meta, `classifyHatchSegs`, `buildMask`, `floodRegion`, `traceRegion`, `snapVertices`); scan mask in `web/src/lib/rastermask.ts` (`buildRasterMask`), trigger policy + `ensureRasterMask` in `TakeoffCanvas.jsx` |
| **Manual measure kit** | Area, Rectangle, Linear, **Curved Line** (smooth spline through clicked points — LF at the true curved length), Surface-Area (walls), Count, Eraser (deduct math), **Flip Horizontal/Vertical** (mirror the selected shape about its own center — an isometry, SF/LF unchanged). Shapes stack by role tier — fills at the bottom, runs above, count pins on top — and selection scans the same stack top-down, so an Area drawn over a Counter/Line/Surface never traps it (#116) | tool state machine in `TakeoffCanvas.jsx` (`performClick`, `finishShape`, `commitPoly`/`commitLinear`/`commitSurface`, `flipSelected`); stacking in `ROLE_TIER`/`stackedShapes`, `TakeoffCanvas.jsx`; mirror math in `reflectVertsNorm`, `web/src/lib/geometry.js`; curve math in `web/src/lib/curve.js` |
| **45°/90° angle lock + aim cursor** | OS pointer hides on canvas; hairlines + house star are the cursor; in-progress segments lock to the 45° family (4° tolerance, ⇧ = hard lock) and the click commits the on-axis point; star swells, band thickens, chip reads angle + live length | `angleSnap()` in `web/src/lib/geometry.js`; the lock block in `moveCrosshair`, `TakeoffCanvas.jsx` |
| **Endpoint snap** | Cursor snaps to true PDF endpoints (spatial hash of extracted vectors) | `buildSnapGrid`/`nearestSnap` in `web/src/lib/geometry.js`; endpoints from `oneclick.ts` |
| **Conditions** | One finish each: color + CAD hatch (16 density-tuned patterns, 4×4 picker with pattern-name caption; `?hatchqa` QA wall for retunes), waste %, ×N multiplier, wall height, border thickness | condition bar + `HatchPattern` in `TakeoffCanvas.jsx`; totals math in `web/src/lib/totals.js` |
| **Supporting Materials** | Per-condition labor type + subfloor type (free text) alongside supporting materials: coverage rate + basis → order qty rounded up; per-material coverage presets (adhesive/mortar trowel notches) + a grout calculator that derives SF/bag from tile geometry | `MaterialsEditor` + labor/subfloor inputs in `web/src/components/TakeoffsPanel.jsx`; presets + grout math in `web/src/lib/coverage.js`; qty math in `web/src/lib/totals.js` |
| **Roll goods** | Opt-in per condition (`roll_setup`: material class, roll width, max roll length, seam/wall allowances, direction, sell unit) → the engine figures lanes, seams, multi-roll splits, and order footage; cuts draw to scale over their rooms in material-true colors, numbered in cutting order; edit mode slides/resizes cuts (undoable via the `rollcut` command, double-click resets); the docked Roll panel shows cuts nested ON the roll with dimensions and drag-to-reorder re-packing; Roll Order LF + Rolls ride the Report/CSV/XLSX and `report.v1` | engine `web/src/lib/rollgoods.js` (pure — Hartman's Summit port); bridge `web/src/lib/rollTakeoff.js`; overlay + drag + memo in `TakeoffCanvas.jsx`; `web/src/components/RollPanel.jsx`; setup UI in `TakeoffsPanel.jsx`; report columns `rollColProfile` in `web/src/lib/reportColumns.js` |
| **PDF layers (OCG)** | CAD-exported sheets state what their ink is — the engine reads it: per-segment layer attribution from marked-content operators, layer names classified into roles (boundary / finish-pattern / annotation / structure / demolition), and the flood mask consuming the stated roles ahead of the hatch heuristics (hidden layers excluded outright); unlayered sheets are byte-identical to before | marked-content stack in `web/src/lib/oneclick.ts` (`extractVectorGeometry`), roles in `web/src/lib/layers.ts`, mask short-circuit in `buildMask`; MCP surface (`sheet_info.layers`, `layers` filters, `layer_bounded` provenance) in `mcp/src/session.ts` |
| **Sheet graph** | The plan-set index for agents: sheet roles with evidence, schedule tables extracted with a citation bbox per cell, room tags with names, detail callouts, and room-tag resolution (tag → room-finish row → finish definitions, every edge cited; unresolved comes back with a reason). MCP tools `sheet_graph` / `resolve_tag` / `find_schedule` | `web/src/lib/sheetgraph.ts` (pure); MCP wiring in `mcp/src/session.ts` + `mcp/src/tools.ts` |
| **Totals & report** | Per-condition Floor/Wall/Border SF, LF, EA, SY, with/without waste (waste-inflated columns labeled "w/Waste") + materials buy list; a **Labor view** column preset surfaces raw Total SF and hides the waste columns for tying quantities to labor externally | `web/src/lib/totals.js`; `web/src/components/ReportPanel.jsx` |
| **Export** | CSV / JSON / **Excel (.xlsx)** / print / **Marked Set PDF** — the workbook carries Summary, By-sheet, Materials, and Shapes-audit tabs (own SpreadsheetML writer, formula-inert strings, full-precision cells); the marked set burns the takeoff into the sheets (colors, clipped hatch, quantity chips, markups) + a legend cover with net totals and a by-sheet breakdown; follows the current light/dark view | export handlers in `ReportPanel.jsx`; `web/src/lib/xlsx.js` (+ `sheetTotals` in `totals.js`); `web/src/lib/markedset.js` |
| **Revisions** | Save the takeoff as a named revision at each bid revision/addendum; compare any two (or one against the live takeoff) as quantity deltas per condition, per sheet, and on the buy list, with a compare CSV; restore auto-banks the live takeoff first | `web/src/lib/revisions.js` (diff), `web/src/components/RevisionsPanel.jsx`; `revisions` store in `web/src/lib/store.js` |
| **Markups** | Freehand highlighter (chisel/round nib, 5 inks, F/M/B sizes, style remembered), revision clouds, callouts, text notes — separate layer, never counted | markup tools in `TakeoffCanvas.jsx` (`placeMarkup` + the highlighter pointer branches); `cloudPath` + `thinStroke`/`strokePathD`/`chiselRibbon` in `web/src/lib/geometry.js`; highlight export in `web/src/lib/markedset.js` |
| **Dark view (negative print)** | ☾ in the zoom cluster inverts sheet pixels in place (one difference pass, an involution — no filter layers, no re-render) with dark hatch/fill variants baked into the patterns | `invertCanvasPixels` + dark pattern ids in `TakeoffCanvas.jsx` |
| **Persistence** | Autosave to IndexedDB + localStorage; survives reload; nothing uploaded | `web/src/lib/store.js` |
| **Sample plan** | One-click demo: a real (public) medical-center floor finish plan | `web/public/demo/`, load button in the empty state |
| **Bring-your-own-AI (opt-in)** | Client-side seam to a vision endpoint **you** configure (OpenAI-style or Anthropic-style; local runtimes welcome, key optional, stored per-browser). First consumer: *read scale with AI* — one title-block snapshot → suggestion in the existing confirm-to-apply flow. Dormant when unconfigured; no telemetry | `web/src/lib/ai.js` (`visionQuery`, config, request/response plumbing); `scaleFromLabel` in `web/src/lib/sheets.ts`; `captureTitleBlock`/`readScaleWithAi` in `TakeoffCanvas.jsx`; `web/src/components/AiSettings.jsx` |
| **Optional AI backend** | Pluggable adapter interface for scale/room/finish suggestions; heuristic default, bring your own model | `server/app.py`, `server/adapters/base.py`, `server/adapters/heuristic.py` |
| **Capture layer (opt-in)** | Local stdlib-only server banks Contribute payloads as (geometry → label) JSONL training rows — hash-gated dedup, verbatim payload archive, atomic mirror into a synced share. The mirror is wedge-proof: share ops run on capped expendable threads (`OPENTAKEOFF_MIRROR_TIMEOUT_S`, 15s default) behind a strand budget, so a stalled sync client can never hang a contribution | `capture/capture_server.py` (see `capture/README.md`); payload builder `web/src/lib/contribute.js` |
| **In-canvas takeoff agent** | BYO-key tool-use loop inside the app: the agent reads sheet text and schedules, aims the same One-Click engine, and stages **dashed proposals** — nothing commits until the human Accept gate; refuses uncalibrated sheets (the scale gate) and whitelists proposal evidence | `web/src/lib/agentTools.js` (tool registry + `agentScaleGate` + `pickAgentEvidence`), `web/src/lib/agentLoop.js`, `AgentPanel.jsx`; `buildAgentCtx` + the accept gate in `TakeoffCanvas.jsx` |
| **Command box (voice wiring)** | Toolbar command line: `carpet one waste 7` / `waste 12` / `label Phase 2` / `clear label` / `note …` — a deterministic transcript→intent grammar dispatched through the exact capability calls the buttons make (no voice-only mutation path, proven by state-equivalence tests); the entry point RFC #59's push-to-talk dictation will feed | parser `web/src/lib/voiceIntent.ts`; dispatcher `web/src/lib/voiceActions.ts`; `buildVoiceCtx` + the Command cluster in `TakeoffCanvas.jsx` |
| **Import takeoff** | Sheet menu → **Import takeoff…** loads a `takeoff_canvas.v1` JSON — the app's own autosave or an MCP session's `export_takeoff` — through the review gate: machine shapes (`origin.reviewed:false`) land dashed in their condition colors until the Accept banner inks them. Merge rules are pure + tested: operator's calibration, conditions, and workspace win; re-import is idempotent | `web/src/lib/importTakeoff.js` (`parseTakeoffImport`, `mergeTakeoffImport`); hidden input + `importTakeoffFile` + Sheet-menu entry in `TakeoffCanvas.jsx`; `web/test/importTakeoff.test.ts` |
| **MCP server** | The engine on stdio for MCP clients (29 tools): load/scale/one-click/**detect-rooms** (batch one-click from the sheet's own room-number labels)/measure/summary/export as agent tools, **edit_condition** (the waste % + ×N multiplier knobs — without them an agent takeoff ships net === gross), **export_report** (the computed `opentakeoff.report.v1` document — the buy list and waste-adjusted nets a pricing consumer reads instead of re-deriving), **measure_surface** + **place_count** (wall SF and EA — all five measure roles reach the wire, #146), **roll_setup on edit_condition** (roll goods figured headlessly, the reply echoes the order, #147), **list_shapes** (the mid-session inventory, #149), **annotate incl. arrow/bubble** (#150), **export_marked_pdf** (the marked-up planset — shapes, hatches, quantity chips, and annotations burned into vector copies of the sheets plus a legend cover, machine-traced work disclosed as pending review; the deliverable, stated in the server's initialize `instructions`), plus **view-sheet** sheet vision (rendered crops with a calibrated 1-ft/5-ft measuring grid and a committed-shapes overlay), same math and provenance as the canvas | `mcp/server.ts`, `mcp/src/{session,tools,pdf,view,marked}.ts`; batch core in `web/src/lib/detectRooms.ts`; report document from `web/src/lib/totals.js` `reportJson`; marked set from `web/src/lib/markedset.js` (see `mcp/README.md`, `docs/MCP.md`) |

## Tested surface

`cd web && npm test` — `node:test` over the pure math: `web/test/geometry.test.ts` (One-Click pipeline incl. the hatch-robust fill and meta emission), `web/test/canvas-geometry.test.ts` (angle lock, hit-testing, metrics, snap grid, highlighter stroke geometry), `web/test/totals.test.ts` (waste, SY, coverage → order quantities, vertical-wall SF), `web/test/coverage.test.ts` (material-kind classification, grout coverage from tile geometry), `web/test/units.test.ts` (metric display layer + ratio-scale math), `web/test/xlsx.test.ts` (the SpreadsheetML writer: escaping, sheet-name rules, styles/filters, workbook tabs, fflate round-trip), `web/test/revisions.test.ts` (revision diff: pairing, display-precision thresholds, sheet/buy-list deltas, compare CSV), `web/test/zone.test.ts` (zone-check classification + rollup), and `web/test/plays.test.ts` (condition plays).

`cd mcp && npm test` — the MCP server over the bundled demo plan: session state + lazy caches (`mcp/test/session.test.ts`), the tool layer over an in-memory client/server pair (`mcp/test/tools.test.ts`), and a full load → scale → one-click ×4 → summary → export round-trip (`mcp/test/e2e.test.ts`).

`python3 capture/capture_server.py selftest` — end-to-end over the wire: contribution rows, dedup on re-contribution, re-capture on retag, health counts, the atomic mirror copy, and the wedged-share guarantees (a hanging mirror folder still banks the row and returns the POST within the cap).

## Extending it

Start with [`AGENTS.md`](AGENTS.md) for the canvas mental model and conventions (coordinate spaces, imperative cursor layer, SVG color literals), then pick your row above. Typical forks: another trade's conditions and supporting materials, a new export format in `ReportPanel.jsx`, or a real model behind `server/adapters/base.py`.
