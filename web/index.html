OpenTakeoff

OpenTakeoff is a free, open-source (Apache-2.0) construction takeoff engine. A person measures plans in this browser canvas; an AI agent drives the same geometry and quantity math over MCP. Every measurement records its scale, its method, and whether a person or an agent made it.

This page is the takeoff app itself, and it needs JavaScript.

For an estimator

Drag in a PDF, image or .zip plan set; there is no account and opening a plan uploads nothing. Set the scale per sheet, trace rooms under the finish tags from the architect's schedule, and get SF, SY, LF and EA, waste-adjusted order quantities, a supporting-materials buy list, roll-goods cuts with seams, and CSV, Excel and marked-PDF exports. User manual

For an AI agent

npx -y opentakeoff-mcp puts the engine on stdio for any MCP client (Claude Code: claude mcp add opentakeoff -- npx -y opentakeoff-mcp). The agent opens the plan, adopts the scale, measures rooms on the wall faces, checks its work on a rendered overlay, and exports a marked planset; its work stays pending until a person approves it in this canvas.
